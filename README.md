# npa-pipeline

Инструмент для работы с официальными нормативно-правовыми актами (НПА) РФ. Состоит из трёх этапов, разрабатываемых последовательно.

## Этапы

1. **Скачивание** (в разработке) — автоматический поиск и загрузка оригиналов документов через API `publication.pravo.gov.ru`, без ИИ в рантайме. План: [`docs/stage1-plan.md`](docs/stage1-plan.md).
2. **OCR** (не начато) — распознавание сканов в текст/DOCX. Движок и точность — открытый вопрос, будет прорабатываться отдельно.
3. **Приёмка в нормативную базу** (не начато) — размещение акта, верификация реквизитов по тексту, карта влияния на связанные артефакты проекта, где эта база используется.

## Статус
